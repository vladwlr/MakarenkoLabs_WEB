# MakarenkoLabs_WEB

Лабораторні роботи з дисципліни **Веб-програмування та веб-дизайн**.

Студент: **Макаренко Владислав**, група **303-ТН**.

## Що є в архіві

- `MakarenkoLab1` — базові конструкції JavaScript.
- `MakarenkoLab2` — DOM, події, робота з елементами сторінки.
- `MakarenkoLab3` — простий калькулятор на Express + JavaScript.
- `MakarenkoLab4` — функції, масиви, матриці.
- `MakarenkoLab5` — Flask + запит з фронтенду.
- `MakarenkoLab6` — об’єкти, класи, просте моделювання.
- `MakarenkoLab7` — дата/час і гра з випадковим числом.
- `MakarenkoLab8` — невелика гра на Express.
- `MakarenkoLab10` — React-компоненти.

## Як дивитися

Для звичайних HTML/JS робіт достатньо відкрити `index.html` у потрібній папці.

Для Node.js робіт:

```bash
npm install
npm start
```

Для Flask:

```bash
pip install -r requirements.txt
python app.py
```

Головна сторінка для швидкої навігації — `index.html` у корені проєкту.
