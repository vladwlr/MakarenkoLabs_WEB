# MakarenkoLabs_WEB

Лабораторні роботи з дисципліни **Веб-програмування та веб-дизайн**.

**Студент:** Макаренко Владислав, група 303-ТН.

## Що є в репозиторії

- `MakarenkoLab1` — базові конструкції JavaScript.
- `MakarenkoLab2` — DOM, події, робота зі сторінкою.
- `MakarenkoLab3` — калькулятор на Node.js/Express.
- `MakarenkoLab4` — функції, масиви, матриці, перевірка чисел.
- `MakarenkoLab5` — Flask-проєкт.
- `MakarenkoLab6` — класи, обʼєкти, методи.
- `MakarenkoLab7` — додаткові JS-завдання.
- `MakarenkoLab8` — міні-гра 1–25.
- `MakarenkoLab10` — React-компоненти.

## Відкриття

Головна сторінка: `index.html`.

На GitHub Pages відкриваються статичні сторінки. ЛР 3, 5 і 8 також мають серверний запуск, але для швидкого перегляду зроблені окремі сторінки, які відкриваються прямо в браузері.

### ЛР 3

```bash
cd MakarenkoLab3
npm.cmd install
npm.cmd start
```

### ЛР 5

```bash
cd MakarenkoLab5
pip install -r requirements.txt
python app.py
```

### ЛР 8

```bash
cd MakarenkoLab8
npm.cmd install
npm.cmd start
```
